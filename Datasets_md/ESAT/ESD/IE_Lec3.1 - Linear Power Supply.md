## REGULATOR Dropout Voltage

It is the difference between the output voltage and the input voltage at which the circuit quits regulation with further reductions in input voltage

Conditions: IThe output voltage must always be lower than the input voltage. 2The greater the difference between the input and output voltages (given the same current) the more power must be dissipated in the regulator circuit, so the hotter it will get.
