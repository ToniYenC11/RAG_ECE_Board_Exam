## Presentation Layer

- Layer 6 is responsible for the ' presentation ' of data.
- It  acts  as  data  format  translator  which ensures  that  data  can  be  read  by  users and applications.
- Layer 6 functions also include data encryption, decryption, compression, decompression.

<!-- image -->

## Presentation Layer

- Layer 6 protocols include:
- JPEG, BMP, GIF, PNG for image formats.
- MOV, MP4, AVI, MPEG for video formats.
- ASCII, DOCX, PDF for file/text formats.
- MP3, FLAC, WAV for audio formats.
- HTML for webpages.

<!-- image -->

## Session Layer

- Layer  5  is  primarily  concerned  with  the dialog among devices.
- This  layer  is  responsible  for  establishing, maintaining, terminating ' sessions ' between devices and/or applications.

## Datalink Layer

- Mostly called the second layer of the OSI model (Layer 2).
- Layer 2 ensures reliable data transfer from the Network layer to the Physical layer for transmission across the network.
- •

## Datalink Layer

- Layer 2 is  responsible  for  error-detection, flow control and physical addressing.
- It  has  two  (2)  sublayers  called Logical Link  Control ( LLC )  and Media  Access Control ( MAC ).

## Network Layer

- The Layer 3 of the OSI model.
- Layer 3 is where the best path determination  is  made  for  packet  delivery across the network.
- The protocol data unit (PDU) for this layer is called ' packets '.
- This layer uses logical addressing scheme using the Internet Protocol (IP) address.

<!-- image -->

<!-- image -->

<!-- image -->

## Routed vs Routing Protocol

1. Routed Protocol - protocols used to carry data  across  the  network  (e.g.  IP,  IPX, AppleTalk).
2. Routing Protocol -protocols used  to build, maintain and exchange information within  or  outside  the  network  (e.g.  BGP, OSPF, EIGRP, RIPv2, IS-IS).

<!-- image -->

## Routing Table

<!-- image -->

- Used to list and determine the best path/route based on the criteria of different routing  protocols  (e.g.  hops,  throughput, bandwidth).
- Routing  table  is  mostly  seen  in  network devices called, routers.

## Internet Protocol Address

- IP  address is a unique logical addressing scheme  used  to  locate  devices  within  a network.
- 32 bits logical addressing scheme for IPv4 and 128 bits or 12 hex digits for IPv6.
- IP  address  can  be  statically  (manual)  or dynamically (DHCP) assigned.

<!-- image -->

## Internet Protocol Address

- IP address is always paired with the Subnet Mask ,  which defines the range or scope of the network.

## Transport Layer

- The Layer 4 of the OSI model.
- Layer 4 is responsible for end-to-end connections  and  data  delivery  between two hosts.
- The protocol data unit (PDU) for this layer is called ' segments '.
- This layer also provides fault detection and error recovery.

<!-- image -->

<!-- image -->

<!-- image -->

## Transmission Control Protocol

- TCP is a connection-oriented protocol.
- Reliable protocol which uses 3-way handshake to establish and maintain connections between devices.
- Capable of error detection and recovery.
- Retransmits lost packets.

## User Datagram Protocol

- UDP is a connectionless protocol.
- Unreliable connection
- This protocol is also called ' fire  and  shoot ' or best effort protocol.
- UDP  is  not  capable  of  error-recovery    and flow control.
- Widely used in real-time data transmission.

## Ports

<!-- image -->

- Ports identify the protocol of the application being used.
- Ports  are  differentiated  by well-known , registered and dynamic ports.
- Well-known ports (0-1023)
- Registered ports (1024-49151)
- Dynamic (Private) ports (49152-65535).
